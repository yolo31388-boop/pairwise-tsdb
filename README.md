# 游戏内时序数据库与监控系统

## 项目描述

游戏内时序数据库与监控系统的bug修复项目。核心模块 `monitoring/tsdb.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 数据写入只存当前值覆盖历史数据
- 数据查询完全没做只能看最新值
- 数据保留完全没做历史数据无限增长
- 数据采集只采集CPU和内存
- 告警完全没做CPU100%也不通知

## 运行测试

```bash
python -m pytest tests/test_tsdb.py -q
```

修复目标：所有 14 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
